Interstate '76 and Interstate '82
=================================

Readers and converters for the Activision vehicular-combat games *Interstate '76* and
*Interstate '82*: geometry, terrain, textures, the horizon renderer, the ZFS and PAK archives,
LZO decompression, and portable-executable unpacking.
