Amplitude and FreQuency
=======================

Readers and converters for the PS2 Harmonix rhythm games *Amplitude* and *FreQuency*: ARK
archives, Milo scenes, DataArray resources, bitmaps, meshes, MIDI, movies, and the streaming
audio pipeline.
