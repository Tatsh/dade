jubeat plus
===========

Converters for the shipped assets of the Konami iOS rhythm game *jubeat plus*: the seven Blowfish
keys, the Apple-optimised PNGs and enciphered ``.tex`` textures, the ``.caf`` sound effects, the
``.jbt`` tune packages and marker ZIPs, the note charts inside a tune package, the property lists
whose data values are enciphered strings, and the pipeline that converts a whole download in one
pass.
