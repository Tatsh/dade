BitRock and InstallBuilder
==========================

A pure-Python, sans-I/O reader and extractor for BitRock / InstallBuilder installers, together
with the password cracker used to recover the password of an encrypted installer. The optional
CUDA and OpenCL back ends are omitted here because they require GPU libraries that are not part of
the documentation build.
