Marmalade SDK
=============

Decoders for assets built with the Marmalade SDK: Derbh (``.dz``) archives, IwResGroup
(``.group.bin``) resources, and the ``CIwTexture``, ``CIwGxFont``, ``CIwMaterial``, and
``CIwModel`` resources.
