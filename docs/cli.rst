Command reference
=================

Every game is a sub-group of the top-level ``destin`` command, so each tool is invoked as
``destin <game> <subcommand>``. The full command tree below is generated from the CLI itself.

The :doc:`usage` and :doc:`utilities` pages cover the ``destin incoming`` extractor in more detail.
