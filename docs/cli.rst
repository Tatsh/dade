Command reference
=================

Every game is a sub-group of the top-level ``dade`` command, so each tool is invoked as
``dade <game> <subcommand>``. The full command tree below is generated from the CLI itself.

The :doc:`usage` and :doc:`utilities` pages cover the ``dade incoming`` extractor in more detail.
